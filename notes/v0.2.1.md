## osscycler is open source

osscycler is now public, under the GNU General Public License version 3:
use it, study it, change it and share it. The README shows what the
screen looks like, and SECURITY.md says how to report a security problem
privately.

## Nothing new to ride

The programs are the same as in 0.2.0; this release brings the project
around them:

- Screenshots in the README: a lap of the figure 8 with your best lap
  as the ghost, and an interval workout on the 400 m oval.
- Releases are now drafted, checked, and only then published, after
  which they can't change: what you download is what was released.
- Every change is checked automatically before it is merged, and a
  release only comes from a release branch, through a pull request.

## Good to know

- 0.2.0 users needn't update: the programs work the same.
- Building from source still needs the ANT+ network key, as
  DEVELOPMENT.md describes; release downloads have it built in.
