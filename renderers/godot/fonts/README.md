# Fonts

`AtkinsonHyperlegibleNext-wght.ttf`: Atkinson Hyperlegible Next, the
variable font (weights 200-800), by the Braille Institute, Applied Design
Works, Elliott Scott, Megan Eiswerth and Letters From Sweden, designed for
legibility (distinct 0/O, 1/l/I). Licensed under the SIL Open Font License
1.1 (`OFL.txt`, beside it); copyright 2020-2024 The Atkinson Hyperlegible
Next Project Authors (https://github.com/googlefonts/atkinson-hyperlegible-next).

Taken unchanged from Google Fonts (`ofl/atkinsonhyperlegiblenext/AtkinsonHyperlegibleNext[wght].ttf`
at commit 66eef70728ca29f28c31cdc5e7947f2c2de73e8d of https://github.com/google/fonts), renamed only to keep
brackets out of the path (the OFL allows that; no Reserved Font Name is
declared). The HUD turns on its tabular figures (`tnum`), so numbers
don't shift as they change. It has no ★ or ◆: the HUD draws those.
